# Application studies: aircraft skin and automotive panel

Two force-inverse design studies on curved panels, each with nine design
forces.  The Checkerboard model uses the production adjoint; the baseline is
OpenSees `ShellMITC4` with central finite differences.

## Run

```bash
cd /home/song/projects/checkerboard_shell
PY=/home/song/miniconda3/envs/allatom/bin/python
PYTHONPATH=/tmp/openseespy_pkg:src:. MPLBACKEND=Agg \
  $PY -m experiments.cmame_round6_applications.run_all
```

Or separately:

```bash
PYTHONPATH=/tmp/openseespy_pkg:src:. MPLBACKEND=Agg \
  $PY -m experiments.cmame_round6_applications.aircraft_skin
PYTHONPATH=/tmp/openseespy_pkg:src:. MPLBACKEND=Agg \
  $PY -m experiments.cmame_round6_applications.automotive_panel
PYTHONPATH=src:. MPLBACKEND=Agg \
  $PY -m experiments.cmame_round6_applications.make_figures
```

## Cases

- **Aircraft skin**: curved trailing-edge panel, left-edge clamp, nine
  actuators near the trailing edge, full-field camber target.
- **Automotive panel**: cylindrical panel, rear-edge clamp, nine fixture
  forces near the free corner, gap/flush target.

## Caveats

- Each model uses its own target generated by the same `f_true`; target errors
  are not an accuracy comparison.
- MITC4 uses black-box finite differences; a MITC4 adjoint would reduce its
  work units.
- The panels are isotropic and idealized; no contact, plasticity, composites,
  thermal effects, or experimental validation.

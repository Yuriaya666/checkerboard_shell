# Design demos (Round 5)

Four bounded design examples that use the frozen position-only Checkerboard
shell.  They are intended to demonstrate **design convenience**, not accuracy
superiority over MITC4.

## Demos

1. **Adjoint gradient check** (`adjoint_check.py`)
   - 9 nodal force design variables, 297 free DOFs, 99 observations.
   - Exact adjoint gradient vs central finite difference.
2. **Actuation shape control** (`actuation_design.py`)
   - Clamped cantilever plate, 9 nodal forces near the free end.
   - Target displacement field generated by a known smooth force distribution.
   - L-BFGS with exact adjoint gradients.
3. **Reference-shape optimization** (`shape_design.py`)
   - Clamped cantilever plate on a pre-curved base.
   - 12 interior height control points (4x4 lattice, clamped x=0 column fixed).
   - Target displacement field generated by a known smooth height perturbation.
   - L-BFGS with finite-difference design derivatives; state tangent is the
     production sparse rank-one tangent.
4. **Large-rotation shape design** (`large_rotation_design.py`)
   - End-moment cantilever strip at `M/Mmax=0.25`.
   - 4 initial centerline heights.
   - Target tip position generated by a known initial curvature.
   - Nonlinear equilibrium at each design; no rotational design variables.

## Caveats

- Demos 1--3 use the linear reference tangent; demo 4 uses nonlinear
  equilibrium.
- Actuation forces are not uniquely recoverable from a displacement target;
  the primary metric is target displacement error.
- Reference-height design from a single transverse load is not uniquely
  identifiable because the response is even in the height to leading order.
  A pre-curved base breaks the symmetry; the height field can still be
  non-unique, so the primary metric is target displacement error.
- No MITC4 optimization baseline is run; the claim is about the 3V state and
  exact tangent, not wall-clock superiority.

# Design demos: what they show

> Status: demos 1--3 complete, demo 4 running.  No formulation changes.

## 1. Adjoint gradient check

The exact production tangent gives design sensitivities that agree with central
finite differences to `1.5e-12` relative.  The adjoint has 297 unknowns (the 3V
free state), versus 18 forward solves for a 9-variable finite-difference
gradient.

File: `ADJOINT_CHECK.md`, `raw_data/adjoint_check.json`.

## 2. Actuation shape control

| quantity | value |
|---|---:|
| design variables (nodal forces) | 9 |
| free DOFs | 297 |
| observations | 99 |
| objective initial | 2.50e-4 |
| objective optimal | 1.06e-12 |
| target displacement relative error | **6.51e-5** |
| force recovery relative error | 0.174 |
| iterations | 13 |
| max adjoint-check error | 1.5e-12 |

The target displacement is reproduced to `0.0065%`.  The force vector is not
unique; different force combinations produce nearly the same smooth
displacement field.  The correct claim is therefore **shape control**, not
force identification.

## 3. Reference-shape optimization

A pre-curved base is used to break the up-down symmetry of a flat plate; the
design variables are 12 interior height control points of a 4x4 lattice.

| quantity | value |
|---|---:|
| design variables | 12 |
| free DOFs | 297 |
| observations | 99 |
| objective initial | 8.58e-7 |
| objective optimal | 5.66e-10 |
| target displacement relative error | **1.60e-4** |
| height-field diagnostic (non-unique) | 0.968 |
| iterations | 20 (iteration cap) |

The target displacement is matched to `0.016%`; the height field itself is not
unique, so the height error is large.  This is a genuine inverse-problem
non-uniqueness, not a solver failure.  For the paper, the primary metric should
be the target displacement (or a richer set of observables), not the recovered
height field.

Figure: `figures/Figure_R5_shape_design.png`.

## 4. Large-rotation shape design

The strip is loaded by an end moment at `M/Mmax=0.25` (90-degree range).  Two
initial centerline heights are the design variables; the target tip position
is generated by a known initial curvature `h_true = A (x/L)^2` with
`A=1.5`.

| quantity | value |
|---|---:|
| design variables | 2 |
| free DOFs | 46 |
| target tip | (6.342622, 8.435393) |
| optimal tip | (6.342623, 8.435391) |
| tip error | **1.86e-6** |
| iterations | 8 |
| `h_true` | [0.0, 0.375, 1.5] |
| `h_opt` | [0.0, 0.374998, 1.499998] |

The target initial curvature is recovered to `1e-6`, and the tip error is
`1.9e-6`.  No rotational design variables are used; the state is solved with
nonlinear equilibrium at the fixed end moment.

Figure: `figures/Figure_R5_large_rotation_design.png`.

## 5. Design-loop cost: three layers

The same 9-actuator target-shape problem is solved three ways.  The first two
use the identical Checkerboard model, linear solver, and L-BFGS settings, so
they isolate the adjoint-vs-FD effect.  The third uses a black-box MITC4 model
with finite differences.

| method | design vars | free DOF | iterations | work | total time | target error |
|---|---:|---:|---:|---:|---:|---:|
| Checkerboard + adjoint | 9 | 297 | 13 | **79 linear solves** | **1.05 s** | **0.0065%** |
| Checkerboard + finite difference | 9 | 297 | 12 | 438 linear solves | 2.08 s | 0.0066% |
| MITC4 + finite difference | 9 | 594 | 17 | 533 forward analyses | 11.85 s | 0.0026% |

Layer 1, **adjoint vs FD on the same method**: `79` vs `438` linear solves
(**5.5x** fewer), optimization time `0.20` vs `1.11 s` (**5.5x** faster), and
total time `1.05` vs `2.08 s`; the common model/tangent assembly is `0.95 s`
and dominates the total.

Layer 2, **state size**: `297` vs `594` free DOF, about `1/2`.

Layer 3, **black-box MITC4 FD**: `11.85 s` vs `1.05 s`, about **11.3x** on
this design loop.  This is implementation-level: the MITC4 loop rebuilds the
model per analysis and uses FD; a MITC4 adjoint would reduce its work units.
The defensible claim is that the exact tangent makes an adjoint design loop
available and cheap, not that MITC4 is inherently slower.

Files: `FAIR_FD_ADJOINT.md`, `FD_VS_FD.md`, `DESIGN_LOOP_COMPARISON.md`,
`raw_data/fair_fd_adjoint.json`, `raw_data/fd_vs_fd.json`,
`figures/Figure_R5_design_loop_comparison.png`.

## What the demos support

- The 3V free state gives a 3V adjoint system.
- The exact sparse-local plus rank-one tangent gives adjoint gradients at
  `1e-12` agreement.
- The position-only design space is nodal positions/forces; no rotational
  design variables are needed.
- The element can be used for shape control and shape optimization.
- In the large-rotation strip demo, the target initial curvature is recovered
  to `1e-6` with two design variables and `46` free DOFs.
- On the same Checkerboard model, the adjoint needs `79` linear solves versus
  `438` for finite differences (**5.5x** fewer) at the same target accuracy.
- In the same 9-actuator design loop, the position-only adjoint loop is about
  `11.3x` faster in total wall time than a black-box MITC4 finite-difference
  loop, with about `1/2` of the free state; this is an implementation-level
  comparison, not a pure element benchmark.

## What they do not support

- Accuracy superiority over MITC4.
- Wall-clock superiority over a rotation-based element (no MITC4 optimization
  baseline is run).
- Uniqueness of actuation forces or reference heights from a single
  displacement target.
- Any FPC/contact/batch claim.

# Design-demo plan (Round 5)

Goal: demonstrate the **application value** of the position-only Checkerboard
shell through four bounded design examples.  No formulation changes.

## Four examples

1. **Adjoint gradient verification**
   - Clamped cantilever plate, linear reference tangent.
   - Design variables: 3 nodal forces.
   - Objective: target displacement field.
   - Compare adjoint gradient with central finite difference.

2. **Actuation shape control**
   - Clamped cantilever plate.
   - Design variables: 9 nodal forces on a patch near the free end.
   - Target: displacement field generated by a known smooth force distribution.
   - L-BFGS with adjoint gradients; report force recovery, displacement error,
     iterations, 3V adjoint size, FD-vs-adjoint cost.

3. **Reference-shape optimization**
   - Clamped cantilever plate.
   - Design variables: 4x4 height control points (12 interior variables).
   - Target: displacement field generated by a known smooth reference shape.
   - Linear reference-tangent solves; gradient-based L-BFGS (FD design
     sensitivity, exact state tangent); report recovered height field,
     displacement error, iterations.

4. **Large-rotation shape design**
   - End-moment cantilever strip, fixed load level (e.g. M/Mmax=0.5).
   - Design variables: 4 initial centerline heights.
   - Target: tip position generated by a known initial curvature.
   - Nonlinear equilibrium per design; L-BFGS; report tip error, iterations,
     absence of rotational design variables.

## Metrics

- Target error (displacement / tip / height field).
- Design-variable count; state/adjoint size (3V).
- Iterations; gradient-check relative error.
- FD-vs-adjoint number of linear solves (where applicable).
- Runtime.

## Deliverables

- `experiments/cmame_round5/` scripts and raw data.
- `DESIGN_DEMO_TABLE.md`, `DESIGN_REPORT.md`.
- Figures: force recovery, shape recovery, large-rotation tip path,
  convergence curves, adjoint check.

## Scope discipline

- No FPC/contact/batch/locking-free new formulation.
- The claims are about **design convenience and compact 3V state**, not
  accuracy superiority over MITC4.
